# Vineeth P — Portfolio Website

A responsive, single-page portfolio built with semantic HTML, custom CSS, vanilla JavaScript, and Bootstrap 5. The visual design uses a professional light theme. It is designed for free hosting on GitHub Pages.

## Project structure

```text
vineeth-portfolio/
├── index.html
├── README.md
└── assets/
    ├── RESUME.pdf
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── img/
```

## Preview locally

1. Extract the ZIP.
2. Open `index.html` in a browser. For a more realistic local preview, use VS Code's Live Server extension.
3. The Bootstrap CSS/JS, Bootstrap Icons, and Google Fonts are loaded from CDNs, so an internet connection is needed for those external assets.

## Publish free with GitHub Pages

1. Sign in to GitHub and create a new **public** repository. For a personal site, name it exactly `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
2. Extract this project ZIP.
3. Upload the **contents** of the `vineeth-portfolio` folder to the repository root. `index.html` must be at the root, not inside an extra nested folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for the deployment to finish. Your site will be available at `https://YOUR-USERNAME.github.io/`.

For a regular repository (not named `YOUR-USERNAME.github.io`), the URL is usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Personalize before publishing

- Replace the name, email, phone, LinkedIn, and GitHub details in `index.html` if needed.
- Add project links or screenshots when you have public URLs for them.
- The Highlights section includes `assets/img/academic-presentation.jpg` and `assets/img/expert-lecture-iiit-kottayam.jpg`; replace these files to update the featured academic photographs.
- The uploaded portrait is used as the profile photo in the hero section. Replace `assets/img/vineeth-profile.jpg` to update it.
- The PDF is included at `assets/RESUME.pdf` and linked from the hero section.
- Check all contact details and project claims before publishing.

## Privacy note

The public portfolio intentionally does not reproduce the residential street address or third-party referee contact details from the source CV. The location is shown only at city/district level. The resume PDF itself is included as supplied; review it before publishing if you do not want its full contact/address/reference details publicly accessible.
